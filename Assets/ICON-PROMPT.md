# HiDPI icon

Generated using the built-in ImageGen tool. The original PNG is kept in `Assets/HiDPI.png`; `Scripts/build-icon.sh` creates the standard macOS icon sizes and `build/HiDPI.icns` with `sips` and `iconutil`, preserving transparency.

## Generation prompt

Use case: logo-brand. Asset type: macOS application icon for HiDPI, a display scaling utility. Create a polished, minimal macOS icon: one crisp silver desktop monitor, straight-on, with an elegant luminous screen and a simple four-corner expand glyph conveying sharper display scaling. A softly dimensional rounded-square tile, harmonious cool tones, clean silhouette legible at small sizes. Centered composition with generous safe margins, square 1024 x 1024 output. Transparent outside the rounded-square tile. No text, letters, watermark, extra objects, or mockup presentation. This is the final icon asset itself.
